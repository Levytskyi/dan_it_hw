# QA Automation with Java

This repository contains coursework and practical assignments completed during the **QA Automation with Java** course at **DAN.IT Education**.

The project demonstrates my progress in Java programming and software testing. It includes practical work with Java Core, object-oriented programming, collections, exception handling, functional programming, Maven, JUnit, REST Assured, Jackson, and automated REST API testing.

New assignments and automated tests are added as I progress through the course.
